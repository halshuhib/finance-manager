تغيير كلمة المرور لحسابك

ربط المزامنة الفورية مع Google Firebase

تخزين محلي فقط

عند تفعيل هذا الخيار، سيتم رفع أي مصروف أو حركة تسجلها من جوالك إلى قاعدة بيانات Firebase السحابية، وستظهر فوراً على كمبيوتر العمل والمنزل بدون الحاجة لتحديث الصفحة!

يمكنك لصق كود الإعداد كاملاً ككائن JavaScript أو JSON كما يعطيه لك موقع Firebase مباشرة.

كيف أحصل على هذه المفاتيح في 3 دقائق؟
  1. افتح موقع Google Firebase Console وسجل بحسابك.
  2. اضغط Create a project وضع أي اسم (مثال: `my-finance`).
  3. اضغط على علامة الويب `` (Add Web App) وانسخ محتوى `firebaseConfig`.
  4. من القائمة الجانبية اختر Firestore Database ثم Create Database في وضع الاختبار (Test Mode).

إضافة حساب مستقل جديد (زوجتي، أختي، صديقي...)

كل حساب يتم إنشاؤه يحصل على بيئة مالية معزولة تماماً (راتب خاص، مصاريف مستقلة، وصندوق ادخار خاص).
